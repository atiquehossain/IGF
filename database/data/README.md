# Bangladesh administrative divisions

`bangladesh-administrative-divisions.json` contains the canonical English names
used to populate the public Division, District, and Upazila selectors.
`bangladesh-administrative-divisions.bn.json` contains the matching Bangla
display labels. Database IDs and English canonical names remain unchanged.

Source: [Bangladesh Administrative Divisions Dataset](https://github.com/open-admin-data/bangladesh-administrative-divisions), Open Admin Data, updated 2026-09-02.

The source data is licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The checked-in files keep only the hierarchy and bilingual display names needed by this application.
